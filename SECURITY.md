# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within PAFFO, please send an email to **hello@paffo.ru**. All security vulnerabilities will be promptly addressed.

## Scope

This policy applies to the source code in this repository. For issues related to the live website at paffo.ru, please contact us directly.

## Disclosure Policy

When the security team receives a security bug report, they will assign it to a primary handler. This person will coordinate the fix and release process.
